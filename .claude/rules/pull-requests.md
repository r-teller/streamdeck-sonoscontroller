# Pull Request Rules

When creating a pull request, always use the template at `.github/PULL_REQUEST_TEMPLATE.md` to structure the PR body. Do not ask the user for the format — read the template and fill it in based on the work done.

Fill in all sections:
- **Summary** from commit messages and bead descriptions
- **Changes** with bead IDs, problem/solution for each
- **Files Changed** table from git diff
- **Beads** section with planned, discovered, and deferred issues
- **Test Plan** from the verification steps performed during wrapup

If the template file doesn't exist, use a minimal format: Summary, Changes, Test Plan.
